# 手机离线语音控制

## 使用

按现有流程连接飞机并完成初始化。保持应用在前台，在“离线中文语音”区域打开开关，点“连续聆听”。首次使用在手机上允许麦克风；识别使用 HarmonyOS 中文离线引擎，不回退到云端。设备缺少离线识别能力时会显示错误，可使用同一区域的文本口令。

每次说一个动作。页面显示最近识别和处理结果；连续短句识别结束后会自动开启下一句。识别错误会停止聆听并显示原因，避免无限重启。暂停和重新开始之间的旧回调不能触发动作。

## 口令

| 操作 | 示例 |
|---|---|
| 八方向 | 前进两秒、后退半秒、向上飞一点、下降一点、左移一秒、向右飞一点、左转一点、右转两秒 |
| 停止 | 停止、停下、悬停、回中、取消动作 |
| 起飞/重飞 | 起飞 → 确认；再次起飞 → 确认起飞 |
| 降落 | 降落、立即降落 |
| 环绕 | 环绕五米 → 确认；准备环绕；停止环绕 |
| 跟随 | 跟随我 → 确认；准备跟随；停止跟随 |
| 滑动变焦 | 滑动变焦 → 确认；准备滑动变焦；停止滑动变焦 |
| 变焦参数 | 半身/全身/远景；倍率二倍/倍率三倍；渐远开启/渐远关闭 |
| 相机 | 拍照、照相、开始录像、停止录像 |
| 媒体 | 相册、下载最新照片、下载最新录像 |
| 其他 | 状态、暂停语音 |

起飞、重飞及三种任务启动必须在独立口令后10秒内确认；也可长按页面“确认”。“确认起飞”不会凭空发起起飞。参数修改、其他明确动作、停止、降落、关闭语音、断开和切后台会取消待确认。操作期间拒绝新动作且不排队；停止和降落可打断。

没有说时长的方向口令（包括“一点”“一下”）使用“安全飞控”滑块的当前秒数，按钮与语音共用该设置，初始值0.5秒。明确说“前进两秒”则以口令为准；指定秒数必须大于0且不超过10秒。结束后回中。“下降”是下杆，不是自动降落；“悬停”仅为回中/停止原生任务的请求，不证明实际静止。

## 原生任务

环绕半径2–10米，写入后独立读回。本轮手动起飞已确认、飞行遥测新鲜且为mode6、没有其他原生任务执行证据时，允许从悬停衔接环绕；普通手动模式缺少任务报告不再单独阻止此路径。跟随、滑动变焦仅支持新鲜遥测确认的地面状态，且每次连接各只允许启动一轮。滑动变焦参数为半身/全身/远景、1–2或1–3倍、渐远开/关；会先清理旧任务、校验参数回显、准备并观察相机录像模式，不额外发送独立录像启动。

任务共享一个控制器；上一个任务未确认结束时拒绝切换模式。执行以新鲜任务状态0505000100（环绕）、050a000100（跟随）、050d000100（变焦）反馈，成功回复00只代表请求获回复。停止后要结合遥测和目视观察。降落先取消准备，尝试停止原生任务，即使停止未确认仍尝试降落。

## 距离和角度

“前进两米”“左转九十度”只在对应方向有实测标定时执行。展开“距离/角度实测标定”，选择方向，填写实际动作秒数及实测位移（米）或转角（度），保存。保存不发送飞行指令。每方向保留最近5条样本，用速度中位数估算；单次最多10米/180度、预计总时长不超过20秒，每段不超过10秒。该方式是开环估算，不是定位或角度闭环控制。
