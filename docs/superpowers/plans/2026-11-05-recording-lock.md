# 录像结束后的本地锁释放

证据：18:31:42转写“给画面中的男生拍一段时间视频”，模型record_start，未执行dolly_zoom。18:31:43开始录像获ACK，随后录制遥测false但recordingRequested一直true。18:32:34重飞轮次3的扫描轮询持续运行，但相机锁阻止扫描。不是扫描计时器再次停止。

修正：相机请求开始后，只有观察到本次新鲜录像true，再观察到连续500ms新鲜idle，才清理本地录像请求标记。未见录像true的未知启动状态继续保守保留。现有落地重飞校验通过后，允许以本次请求至少1.5秒后的新鲜地面停桨与相机idle回报释放旧相机锁；仍在录制或遥测旧则不释放。保留媒体基线供语音下载重试，不自动重发快门或启动任务。
