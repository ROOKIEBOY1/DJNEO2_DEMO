# 悬停启动原生运镜任务

目标：普通起飞后的悬停状态，通过一次语音提出环绕、独立跟随、带主体和参数的滑动变焦，点击已有确认按钮后自动准备并启动；不再要求用户提前在地面准备。

已证实的根因：模型正确返回 dolly_zoom，App 本地参数修改与地面准备限制阻止执行。原工程 dolly 有已准备后的空中启动，但 prepare 与独立 follow 仍仅允许地面。

方案：复用既有报文，增加显式 prepareHover 入口，严格要求本轮起飞已确认、普通 mode6 悬停、任务空闲或手动相机 mode9、无下降/移动/原生执行、相机空闲及链路新鲜。已有主体锁定先释放并观察普通悬停，写入参数和相机模式，再选择或重新选择目标。follow/dolly 仅在新鲜匹配的 mode26 跟踪框下发启动；环绕不宣称以指定人为圆心。所有阶段响应不匹配或取消即终止，不自动重试启动。

沿用单连接 follow/dolly 各一次限制，不把 ACK 当执行成功。新增空中准备和独立跟随空中启动为待实飞验证路径；不向飞机自动发送测试动作。
