# 拍摄方案、任务进度与对话内视频 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按用户三张参考图，将主体确认后的拍摄体验改成方案、一键执行、任务进度和对话内视频结果。

**Architecture:** 保留真实起飞、扫描、选人及原生运镜链路，在GroundDollyWorkflow中加入可过期的方案阶段。ArkUI对话卡片呈现方案和真实任务进度；成片回传后在卡片内播放。保存复用系统图库授权和分段缓存，但不跳转系统图库、不收起预览。

**Tech Stack:** ArkTS、ArkUI、现有原生图传和图库接口、Node测试。

**Spec:** 用户2026-11-06的三张截图及六项修改要求（本文件记录具体落实方式）。

## Global Constraints

- 去掉固定“好的”回复及主体确认旁的取消按钮；选中框为无文字粉色边框。
- 确认主体只生成方案，随后点击“一键执行”才启动录像和运镜。
- 方案取当前已确认的主体和参数；不虚构调整高度、自动返航或风险评估能力。
- 任务期间显示实况下方进度块；“立即返航”“手动接管”“一键成片”仅演示，不下发飞行或媒体编辑指令。
- 回传成功后在对话内播放本次全部视频，用户点“保存至相册”才启动系统保存授权；保存后预览保留。
- 保留真实降落入口、取消会话与过期校验、单一稳定图传Surface、两段录像回传和重试。
- 直接在用户持续使用的当前工作区修改，不提交或推送，不自动发送飞行动作或安装。

## Review Focus

- 主体确认与执行分开，重复点击、超时、断连、降落、目标变化均不可启动旧方案。
- 新任务不能显示旧成片；多段录像均可播放保存，保存重试不重复写入已成功片段。
- 进度数值只取新鲜且已验证的遥测；未知高度和实际焦段不伪造，目标倍率明确写为计划参数。
- 虚拟操作不接到飞行指令，真实降落按钮保持可见；保存不离开App。
- 消息/进度变化不销毁重建图传Surface；新视频重置播放器，离开/开始新请求停止旧播放。

## 验证与审查记录

169项测试通过，签名构建成功。首次构建发现ArkTS不支持对象展开，方案副本改为明确复制白名单参数，保留防外部修改测试。审查发现实时遥测过期会把已回传视频重新隐藏，已增加控制器持久的agentVideoResultReady：只有完整视频组回传后置true，新拍摄/照片/地面流程/连接重置清false；成片呈现不再依赖上一任务的实时activeOrUnknown。新增红绿测试覆盖断连、遥测过期、失败后重新下载、新拍摄先清旧结果、保存原片和并发互斥。审查复查无重要问题。

主路径按用户默认地面Demo实现方案阶段；隐藏工程页同步增加一键执行。现有空中通用动作仍保留自身确认链路；该路径在准备期间的标题可能短暂保留前次状态，原地面Demo已提前清理旧结果。
