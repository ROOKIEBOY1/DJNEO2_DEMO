# 特写组合运镜 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to execute the independent tasks and review the integrated result.

**Goal:** 用户说“帮黑色衣服的男生拍一段特写镜头”后，沿用选人确认、方案、一键执行，完成滑动变焦后自动衔接同主体的2m环绕。

**Architecture:** 仍由VLM返回白名单动作，新增dolly_zoom的固定recipe=dolly_circle，不接受任意动作数组。本地组合调度在第一段任务确实结束、录像完整回传、身份/会话仍有效后，按原版已记录的同主体圈拍路径启动环绕。两段任务全部视频作为同一结果组呈现，所有真实运动仍通过现有受控服务。

**Tech Stack:** ArkTS、ArkUI、现有NativeTaskService/CaptureMedia、手机直连DeepSeek。

**Spec:** 本次用户明确要求环绕也围绕原来选中的男生，不接受无主体的普通环绕。原版subject_hover_console.py的start_circle、mission_target及ordinary-hover-subject-20261104-151313/152232实机记录提供保留同ID跟踪后直接010500启动的依据；最终物理取景仍须真机验证。

## Global Constraints

- “特写镜头/特写视频”使用固定组合：滑动变焦→同主体环绕，默认半身/3倍/渐远开启，环绕半径固定2m；普通希区柯克仍是单任务。
- 确认主体和一键执行沿用现有界面，方案清楚显示两个步骤；途中不再弹确认。
- 等待真实任务完成及视频写入/回传，禁止按固定延迟认为第一段结束；当前CaptureMedia必须先处理上一段，才能开始下一段。
- 环绕启动前必须验证初始目标的同一新鲜ID、同一会话/飞行轮次、未降落、模式和相机就绪；失去身份连续性时停止接力，不猜编号、不改选他人。
- 同主体Circle启动只沿用原版已观察到的保留mode26跟踪直接启动路径，不在选人后重新写Circle模式以免丢失主体。
- 所有阶段可取消，降落/断连/切后台取消后不得再启动后续步骤；超时和未确认启动不重试运动。
- 滑动变焦及环绕产生的所有片段都保留，完成后在对话内统一显示和保存；部分失败保留已下载素材并提示未完成。
- 不自动安装，不发送实际飞行指令，不提交或推送。

## Review Focus

- 无真实结束/相机空闲回报、录像未回传时不启动环绕。
- 两步之间跟踪ID丢失/变化/陈旧、会话重置、降落、取消时不再发启动。
- 第一段回传完成不得被UI提前当成整个组合完成；第二段失败不丢第一段素材。
- 普通单段拍摄、单独环绕、单独语音选人和现有多片段回传保持兼容。
- 模型否定/问句/仅改参数不可触发组合；recipe只接受固定值且只属于dolly_zoom。

## 首次真机联调：启动切换空框误停

用户安装后反馈“特写组合未完成”。归档hilog.094–098及界面核对：12:47:37.966滑动变焦启动ACK，12:47:38.117已收到停止ACK，随后38.118跟踪false但候选/目标仍为11；38.369恢复同ID11。44.665任务退出，53.626回传1段40,211,003字节/5秒录像，没有Circle准备或启动。NeoSession日志的set/id前缀虽写0x，实际用%d输出：set35/id19是0x23/0x13启动，set35/id21是0x23/0x15停止。

根因：新组合保护在每次snapshot.tracking为false时立即把trackingAt视为缺失并停止，未容忍启动换模式期间的约250ms跟踪报告空窗。原PC主体Circle实机记录也出现约218ms正常启动空框，随后恢复同一ID，因此空框不等于明确换人。

修复：新增CloseupSubjectGuard，以最近一次确证同ID的实际trackingAt维持原有1000ms证据窗口；缺失/空候选/旧时间/未来时间不刷新窗口，新鲜其他ID立即停止。NativeTaskService在最终选中目标校验完成、真正发启动前保存initialTargetTrackingAtMs，不使用准备前旧观察、不使用当前时钟或ACK伪造证据；任务重置清除该值。waitForCloseupMedia以该值初始化保护，仅在仍可能执行时检查，已确认结束的空框不影响下载；环绕启动前仍要求500ms内同ID的新画面。误停时新增明确的主体保护和停止回复日志。

启动空窗集成用例先红后绿；最终212项测试和签名构建通过，涵盖250ms恢复、1000/1001ms边界、持续缺失不续期、真实换ID立即停、过期/未来时间、结束空窗及实际启动证据时间。修正版为diagnostics/closeup-gap-fix-signed.hap，尚未安装，实际组合仍待复测。
