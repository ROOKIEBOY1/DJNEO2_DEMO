# 原生任务执行过程诊断与重飞轮次

最近两次启动确认17:39:48、17:41:42，13秒及17秒后有降落请求，未见新增录像日志。现存日志无法回溯原生执行阶段，不把启动ACK当完成、不推断主体丢失或飞机自主退出。

明确问题：App在prepareGroundedCycle成功后只清FlightCommandService及主体，NativeTaskService.startedAt仍指向上轮任务，手动相机状态会被activeOrUnknown判为活动，阻断扫描及拍照。

实现：仅在现有新鲜落地停桨校验成功后，清理上轮原生任务的准备/启动状态，同时保留单连接任务使用次数限制。增加只读的原生任务状态变化记录，包含任务payload、飞行模式、相机录像状态、目标编号以及已观察到执行/录像的证据；每次状态变化记录一次，任务启动ACK与实际执行明确分开。不得为了诊断自动重复启动。
