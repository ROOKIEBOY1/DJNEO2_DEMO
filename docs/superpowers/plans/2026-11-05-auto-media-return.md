# 拍摄后自动取回原片

**目标** 拍照后自动显示本次照片，普通录像和原生运镜录像结束后自动显示本段视频，沿用已验证的图库保存控件。

**范围** 同时覆盖模型动作、原控制台拍照录像入口、原生任务录像结束及已有希区柯克窗口。明确停止操作和断连可取消传输。

**实现** 新增 CaptureMedia 服务记录拍摄前目录和会话。照片最多等待30秒、视频最多等待60秒发布新文件。目录中唯一新增的对应类型原片连续两次大小稳定、相机和任务均空闲后才下载。禁止使用旧文件代替本次素材。相机确认与文件取回分别反馈，失败后保留拍摄记录供语音下载重试。

**验证** 目录延迟发布、旧素材排除、视频停止前不下载、文件大小变化、会话切换、取消、模糊新增结果、普通和原生入口。

**复查修正** 停止录像期间的下载也登记取消令牌，降落及停止可取消；降落过程中不新建下载任务，落地遥测确认后再取回。拍摄指令发出前的错误释放素材基线，飞机明确拒绝快门时也不留下不存在素材的等待记录；仅已发出但未确认的拍摄保留记录。对应取消用例和快门拒绝用例已复现失败后通过。

**使用方式** 拍照确认后自动取回照片；停止录像确认后等待相机空闲及视频目录稳定，再自动取回原片；原生任务录像观察到开始与结束后自动取回。继续沿用预览下方的保存至图库，保存成功后预览收起。失败时不替换成上一张照片或上一段视频，可语音下载重试。
