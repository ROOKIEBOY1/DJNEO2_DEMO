# 小艺风格半模态拍摄对话

目标：打开App自动出现半模态对话，以底部语音入口发起已实现的地面一句话拍摄。右侧展示用户原话，左侧回复“好的”并展示实时画面；粉色选中框和一次主体确认保持；灰色小字显示真实阶段。录像回传完成自动提示“是否接受视频”，点“是”保存本次全部录像并直接进入系统图库播放。

用户最新要求：不等待或确认落地，不增加落地条件；直接打开系统图库。现有App后台降落断连行为已告知，继续保留。

设计：采用ArkUI原生bindSheet（默认约70%屏幕，可拉高）、浅色圆角面板、灰白聊天背景、蓝紫粉渐变语音图形。面板内保留可见降落入口，原控制台和工程设置可通过关闭面板访问；只有对话视频拥有图传surface，关闭后恢复主页面。语音识别及VLM仍在App内完成。

图库：使用系统授权保存接口处理一组录像，缓存已保存的图库URI，防止重试重复保存。写入并关闭文件后才启动系统图库。用户拒绝保存、写入失败或图库启动失败时保留本次原片和重试入口。普通保存到图库流程不受影响。系统可能显示自己的保存授权窗口。

## 后续真机反馈与修复

半模态版已覆盖安装并确认自动显示对话界面。用户随后反馈回传失败、不要透出旧控制台。读取设备归档hilog.947/948确认：拍摄前最新0144，拍后新增0145（45,216,635字节）和0146（35,822,820字节）；0145完整落盘，0146下载报“TCP connection closed before the complete media response arrived”，对应MEDIA_RETURN_PENDING，第2/2段失败，尚未进入系统图库保存阶段。

修复：连接关闭/传输错误/无数据超时标记为可恢复异常，仅对当前失败HTTP范围最多尝试3次，失败响应中的残缺字节丢弃；保留已校验范围、严格大小/Content-Range/强ETag校验。取消或校验错误不重试。本地重试按钮复用CaptureMedia成功分段缓存，不调用模型。灰色步骤显示真实回传进度及失败原因。

界面默认仅显示渐变空背景与对话面板；原控制台仅由长按“小艺”进入工程设置时显示。保留不可见warmup Surface，确保首次语音前接收解码参数，避免删除原页面后首次图传无画面。关闭面板后点击背景可重新唤起。此轮修复仍需安装复测连接中断后的恢复。
