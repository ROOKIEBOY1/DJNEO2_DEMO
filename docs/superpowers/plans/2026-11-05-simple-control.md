# 三按钮控制与自动主体扫描实施计划

**目标** 普通起飞悬停后自动扫描，主界面保留起飞、降落、语音控制，完善指定主体拍照并展示本次新照片。

**设计** 保留原控制台作为长按标题可进入的设置视图，实时视频始终使用同一个 Surface。主界面自动连接默认飞机并初始化，连接失败显示原因并可点状态重试。自动扫描仅在新鲜的普通悬停状态、无跟踪、无拍摄及任务时运行，保持两秒后复用已有扫描指令。每轮飞行最多三次尝试，降落、重飞、断连、原生任务与拍摄之间隔离。

**执行约束** 起飞继续长按确认，降落保持本地直接入口。语音运镜及方向移动继续独立确认。指定主体拍照必须锁定同一编号并等待稳定回报，读取拍前目录，拍后只下载新增照片，失败不得展示旧照片作为结果。

- [x] 指定主体拍照的锁定等待和新增原片下载，测试失败不按快门及跨会话取消。
- [x] 主界面三按钮及设置视图，保留临时确认控件与媒体展示。
- [x] 本地测试、签名构建和代码复查，明确真机验证范围。

## 用户调整素材保存流程

用户要求暂时取消拍照后的自动原片回传，保留语音下载。已移除拍前目录查询和拍后新增照片轮询，主体锁定及拍照确认仍保留。

语音下载后的照片和录像预览增加系统 SaveButton，点击后使用 MediaAssetChangeRequest 导入图库。仅 applyChanges 成功后清除对应预览，失败保留，保存期间新下载的预览不受旧保存完成影响。74项本地测试和签名构建通过，图库保存版已覆盖安装。真机日志记录“原片已保存到系统图库”，具体图库展示由用户核对。
