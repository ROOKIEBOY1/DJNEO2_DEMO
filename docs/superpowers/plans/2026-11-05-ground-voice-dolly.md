# 地面一句话滑动变焦 Demo Implementation Plan

**Goal:** 地面一句话发起拍摄，自动起飞、扫描、VLM选人，只确认一次主体后开始运镜并沿用自动素材回传。

**Architecture:** 两阶段云端请求：地面仅解释拍摄意图和参数，悬停后用新画面解析主体编号。独立流程对象管理取消、单次确认和有效期；AppController复用现有起飞、扫描、锁定、悬停运镜，不把旧的地面观察复用于空中动作。

**Tech Stack:** ArkTS、现有DeepSeek HTTPS客户端、Node测试、DevEco签名构建。

用户已确认流程并要求实施。保留三个主按钮、普通语音指令和粉色选中框；只对地面明确的滑动变焦拍摄意图启用此流程。

- [x] 先写流程测试：顺序、唯一确认、无目标不拍、失败不继续、降落取消、确认过期。
- [x] 实现流程对象；地面云端意图与空中选人提示使用独立阶段，模型响应继续受既有动作白名单验证。
- [x] 控制器接入新观察与选人确认，主UI显示进度和“确认主体并拍摄”；取消、降落、断线使流程失效。
- [x] 完整测试及签名构建；不发送真实飞行指令，真机安装/飞行验证另行与用户进行。

重点检查：旧地面请求跨起飞轮次不能直接执行；延迟云端响应不能在取消后选人；用户重复点击不能重复启动；无候选或多主体不明确不能使用默认第一个；确认时跟踪编号变化不能启动。

实现记录：GroundDollyWorkflow管理阶段、取消和30秒主体确认有效期；AppController.runCloudVoiceRequest仅在新鲜落地停桨状态启用地面意图阶段。自动起飞后等待最多30秒获得悬停扫描候选，重新取帧发起视觉选人；选中回报确认后展示粉色框。确认按钮重新取帧核对目标，直接进入既有startAgentSubjectTask与自动素材回传，不再产生第二次动作确认。

验证：134项测试通过，签名构建成功，独立只读复查未发现重要缺陷。真实DeepSeek文本请求验证普通滑动变焦、三倍半身、否定请求及仅设置请求，分别返回dolly_zoom、dolly_zoom（半身/3倍）、none、set_dolly。此验证不发送飞行指令；真机安装、画面选人和完整飞行仍待验证。
