# 手机直连云端VLM

用户已准备手机同时连接飞机Wi-Fi并通过热点上网，要求把电脑接收器的云端逻辑迁入App，日常不再依赖电脑或USB。

设计：沿用官方DeepSeek HTTPS接口及deepseek-flash，App复用现有带编号JPEG、自然语言、上下文与动作校验。移植相同提示词和请求格式；RCP HTTPS客户端禁止跳转、不自动重试动作请求、总时限仍受20秒样本有效期约束，限制响应大小，取消/后台/轮次变化立即使请求失效。保持连接复用以降低时延。

云请求使用系统默认上网网络，检查互联网能力且排除192.168.2.x飞机接口，不修改进程全局网络。无人机UDP和原片下载继续由现有NetHandle绑定飞机Wi-Fi。双链路通过手机实测核对。

密钥：AssetStoreKit设备解锁可访问，不入源码、不入HAP，不记录。工程设置提供密钥保存、清除、连接测试。沿用用户已授权的本地apikey.txt，一次性经hdc debug-app私有目录导入，写入安全存储后删除临时文件。之后不依赖USB导入文件。测试连接不连接或控制飞机。

文件：DeepSeekPayload.ets及AgentPrompt.ets负责纯请求/响应协议；CloudVlmKeyStore.ets负责系统资产存储和一次性导入；CloudVlmClient.ets负责RCP网络、取消、错误、时限；AppController和Index负责设置与替换主语音请求入口。旧USB工具保留为调试兼容，不作为普通入口或隐式回退。
