# 语音视觉动作入口实施计划

> 执行使用 superpowers:executing-plans，在当前工作区逐项完成。

**目标** 将主体选择与切换、滑动变焦、环绕、拍照录像、原片下载和八方向移动接入 DeepSeek。

**设计** 模型每次返回一个有类型的动作，App 校验请求身份、会话、飞行轮次和参数，调用现有服务执行。云端密钥继续由电脑接收器持有。版本 2 USB 请求返回有长度前缀的 JSON，旧版选人协议仍可用。

**范围约定**

- 新增动作 select_subject、cancel_subject、set_dolly、dolly_zoom、circle、photo、record_start、record_stop、download_photo、download_video、move、stop、none。
- 运镜启动及方向移动由 App 提供独立确认。确认十秒过期，确认后再次核对状态。停止操作保留本地入口。
- 移动单位先支持秒数，方向八种，单次 0.1–10 秒，省略时使用 App 当前时长。
- 下载以当前飞机目录最新素材为准，并在 App 展示原片。
- 空中滑动变焦沿用本轮预备任务要求，地面可先准备，再独立确认启动。模型不能绕过准备或遥测检查。
- 普通动作无需有效主体候选或解码帧，视觉选人需要带时戳的真实图像。

**文件**

- core/domain/AgentAction.ets 定义动作、请求和响应格式以及校验。
- AppController.ets 提供模型观测和本地执行入口，保存确认请求及媒体结果。
- core/platform/VlmUsbExport.ets 增加版本 2 JSON 收发，处理 TCP 分片、大小和超时。
- tools/deepseek-selection.cjs 增加动作规划和服务端结果校验。
- tools/receive-vlm-sample.cjs 兼容新旧协议并返回与请求绑定的结果。
- pages/Index.ets 复用语音入口，展示确认、执行反馈和下载的照片视频。

**验证重点**

- 无候选、无图像时可规划拍照或移动，不能选人。
- 非法动作、未知字段、编号不匹配、过期响应、跨会话及飞行轮次均不执行。
- 未确认动作不会发起飞行命令，确认只消费一次，停止和断开会废弃待确认动作。
- 运镜准备、选人及启动失败要终止后续步骤并反馈真实错误。
- TCP 响应分片和异常响应不能执行半个结果。

用保存画面调用真实 DeepSeek，验证了主体切换、指定目标滑动变焦、环绕、移动、拍照录像和素材下载等动作输出。在独立端口验证版本 2 无图拍照规划及版本 1 双候选选人回包。测试未向飞机发送任何动作，新包尚未覆盖安装。

整体只读复查未发现阻塞问题，指出的确认过期提示已同步到控制页。

### 实施调整

- 增加 prepare_dolly 作为已有地面准备流程的模型入口，便于普通起飞后使用空中变焦。
- 保存图片的真实模型测试出现坐标对应错误，在实际 JPEG 上绘制候选编号后重新测试，白衣目标和另一个目标均返回正确编号。
- 下载以最新原片为准，下载前要求新鲜相机空闲状态和已结束的原生任务。
- “停止聆听”关闭语音输入，正在执行的操作仍使用现有停止/回中入口停止。
