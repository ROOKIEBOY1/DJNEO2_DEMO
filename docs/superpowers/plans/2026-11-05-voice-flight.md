# 语音起飞与降落

需求：当前语音控制支持直接说起飞、降落，不要求点击对应飞行按钮，原有按钮保留。用户已明确选择直接语音发起起飞。

实现：明确的单句起飞/降落先在本地解析，复用takeoffConfirmed/land共享飞控入口，避免依赖USB/云端和等待主体扫描。仅匹配肯定的完整常用口令，否定、问题、组合和条件句不作本地动作。云端动作协议增加takeoff/land且不增加第二个点击确认，模型支持更一般的肯定请求，明确禁止否定/假设/询问和多动作自动执行。起飞要求相机观测之外的新鲜实际落地停桨状态、当前无忙碌，降落走现有抢占取消与原生停止流程。

繁忙时语音入口仍可打开以接收本地降落，其余命令不排队。语音启动仍由用户点语音按钮，不做后台常开监听。每条语音只执行一次；云端的会话、轮次、时效及重复响应校验保留。
