# 一键成片首版设计（已授权实施）

## 目的与用户已选择的范围

把对话内目前假的“一键成片”接成真实闭环：用户已选第一版就包含固定配乐和淡入淡出。全部处理放在手机，不依赖电脑或把原片上传云端。原有起飞、选人、运镜、统一回传流程保持。

## 用户体验

1. 本次拍摄成功且全部原片已取回后，点击“一键成片”。
2. 小艺展示真实阶段和进度：“正在整理拍摄素材 → 正在添加配乐与淡入淡出 → 正在导出成片”。没有可计算百分比的阶段只展示阶段，不假造进度。
3. 成功后，在当前对话内出现一条可播放的成片，显示时长；“保存至相册”保存这一条成片，沿用系统保存授权。原片可切回查看和保存。
4. 同一组素材重复点击直接打开已生成作品；失败可重试，原片保留。合成中可取消，取消只影响剪辑；关闭对话可继续合成，重新打开能看到进度或结果。不启动系统图库或其他编辑应用。

## 首版默认成片效果（实施建议）

- 保留本次所有原片及其顺序，整段组合，不做自动精彩片段筛选，不把第1/2片臆断为滑动变焦前进/回退。
- 保留原画面比例和主体构图，必要时留边；最高输出1080p，最高30fps，低于该规格的素材不为了输出放大。MP4 / H.264 / AAC，便于对话和图库播放。
- 用户指定Scott Buckley的《Titan》，从官方音源内置，循环覆盖整条成片；默认只保留配乐，不混入原片音轨，不需要用户选择音乐文件。遵循官方CC BY 4.0署名，在界面、随包授权文件和输出作品metadata中保留作者/曲名/来源/许可及循环与淡入淡出修改说明；导出作品末尾显示简短音乐署名，不另加片尾时长。
- 画面整条开头及结尾各约0.6秒从黑色淡入/淡出；片段之间先使用自然切换，不额外实现交叠转场。配乐头尾各约1秒淡入/淡出，极短素材按时长缩短效果。
- 不加字幕、片头卡、贴纸或水印；不自动裁切为竖屏。

用户于2026-11-06要求“直接执行吧，音乐就用Scott Buckley的《Titan》”，授权依此实施。淡入淡出时长、导出规格由实现者按本设计默认值决定。

## 现状与约束

AssistantSheet的一键成片当前只调用demoAction。CaptureMedia已有拍前目录基线、结束确认、目录稳定和下载后复核；本次素材按路径排序，最多八段。CloseupMediaGroup保留本轮URI并去重。现有VideoAssembler只重组实时图传包，不是影片剪辑器。

目前没有持久化“MP4对应哪一步任务、片内运镜起止时间”的剪辑清单，因此不承诺自动去掉等待或自动挑选最好片段。组合失败/取消后也可能有已返回的部分素材；首版只在组合completed且本次素材全部取回时生成完整成片。单任务也必须结束并且本次回传完成。部分素材保留原有播放和保存能力，不冒充完整成片。

本地编译SDK为API21/6.0.1。AVTranscoder仅提供单输入转码，不能完成本需求的多片段与画面淡入淡出。本机没有已验证的完整剪辑SDK；HMS Video Editor Kit官方产品为Android，不直接用于此ArkTS项目。真实性能和源视频编码必须先用实际素材验证，不能预先承诺几秒成片。

## 方案与选择

- 简单合并：Native解封装、重排时间戳、重新封装，参数兼容时可免重编码，快且保留原压缩画质；无法提供用户这次选择的画面淡入淡出。
- 本地模板成片（用户选择的效果，建议的实施方案）：在现有Native工程中新增独立媒体管线，视频解码、缩放/淡入淡出渲染、硬件编码；固定音乐生成PCM后AAC编码，最终封装一个MP4。无需上传大文件，符合独立手机Demo；开发量和导出耗时高于简单合并。
- 云端渲染：上传原片、服务端合成、再下载。可扩展复杂模板，但当前没有该服务、会增加传输等待，暂不选。

首选系统Native媒体API与GPU，不引入未经验证的鸿蒙FFmpeg依赖。若真实素材无法被当前设备解码/编码，明确报告不兼容并保留原片，不静默退成假效果或云端上传。需要替换媒体引擎时先说明依据。

## 组件与状态边界

ArkTS持有本地剪辑任务和不可变素材清单，Native负责媒体探测、解码/渲染/编码/封装。导出过程在工作线程运行，使用独立的取消令牌和进度，不复用飞行busy、控制链路或相机命令；降落入口保持可用。

任务状态至少包括idle、probing、rendering、finalizing、completed、failed、cancelled。生成任务绑定素材组及其版本。开始新拍摄或更换素材组时，不把旧结果发布到新任务卡片；完整关闭应用后不承诺恢复未完成导出，已完成成片可由本地清单恢复。

探测真实源视频的时长、编码、尺寸、帧率、旋转及色彩信息。输出时间线连续；进度按已处理的实际媒体时长报告。只有编码器结束、封装写尾成功、文件非空并通过媒体元数据/可播放性检查，才发布完成和启用保存。缓存键包含素材身份和模板版本，防止新素材命中旧作品。

输出使用新的文件路径，绝不覆盖或删除原片。临时输出取消/失败后清理；已生成作品保持可播放并允许保存重试。保存成片沿用GalleryVideoReceiver/SystemGallery能力，但必须显式传入成片URI，不能误存整组原片。

## 验收

- 一段滑动变焦、多段滑动变焦、滑动变焦加环绕，均用完整本次素材生成一个实际MP4。
- 对话内实际播放能听到配乐、看到头尾淡入淡出；实际总时长应等于全部原片时长之和（允许编码帧级取整），完整运镜保留。
- 保存至相册后系统图库能播放同一条成片，App内预览保留。
- 重复点击、取消、失败重试、换素材组、折叠/重开对话、保存授权取消有一致的状态和结果，不影响飞机控制。
- 在用户真机上测量真实处理时间、内存与画面方向/比例；源素材分辨率或色彩格式不支持时明确失败，不报告成功。
