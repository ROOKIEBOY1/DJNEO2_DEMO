# 手机语音与原生任务迁移

用户已确认迁移原 Python 工程的跟随与滑动变焦，并统一接入语音。

采用现有 ArkTS 服务和 HarmonyOS 离线中文识别。原生任务共享一个控制器，防止环绕、跟随、滑动变焦同时操作。保留已验证的连接流程和手机私有目录中的档案、路由状态。

口令覆盖八方向和秒数、中文数字、常见别名、起飞/重飞、停止/降落、2–10 米环绕、跟随、滑动变焦（半身/全身/远景、2/3倍、渐远开关）、拍摄与媒体。米数/角度使用本机实测标定换算；无标定明确拒绝。危险启动要求独立的确认事件，10秒过期；停止、降落、关闭语音、断开和切后台清除待确认并取消正在准备的操作。没有排队的飞行动作。单向最长10秒。

跟随与变焦按原版限制从地面启动，每连接只发起一轮；任务模式、参数、录像模式的回显和新鲜遥测必须通过。任务ACK不能表示已执行，停止任务不能表示已落地。停止失败仍尝试降落；不自动重放未确认的启动。相机与下载也必须可取消。

连续聆听通过串行短句离线识别实现，停止/后台使旧回调失效，不无限重试识别错误。显示最近识别、结果、待确认和任务状态。

验证：离线运行真实ArkTS核心逻辑（TypeScript转译，平台边界替身），逐字节核对原版任务报文；覆盖否定/混合口令、超时确认、取消后的后续发包、任务互斥及录像前置。使用本机SDK构建签名包。安装前确认手机已落地；只进行界面/识别验证，不自动实飞。
